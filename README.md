# WELTWERK v0.2.20 – World Tappables / Baum v1

Einzelne `index.html` ohne Unterordner oder Build-Schritte. Die bestehende WELTWERK-Seite auf GitHub Pages lässt sich direkt aktualisieren.

## Neu

- Baum in 50-m-Reichweite antippen: neuer bildschirmfüllender Low-Poly-Sammelbereich.
- Je Baum 3 Stammplätze mit garantiertem Holz sowie 3–6 Zweigplätze mit garantierten Zweigen.
- Stamm-Boni je Platz: Nichts 82,5 %, Pilz 10 %, Harz 5 %, Eichhörnchen 2,5 %.
- Zweig-Boni je Platz: Nichts 32,5 %, Blatt 50 %, Zapfen 10 %, Apfel/Birne/Kirsche je 2,5 %.
- Je Baum 2,5 % Bienennest und 1,5 % Vogelnest. Jedes Nest bietet zwei untersuchbare Fundplätze.
- Seltene Tiere sind **virtuelle Begegnungen**, keine Tier-Gegenstände; echte Nester oder Wildtiere niemals berühren.
- Einzelne Fundstellen sammeln oder „Alles einsammeln“ nutzen.
- Teilfortschritt bleibt auch nach Schließen/Neustart erhalten. Keine neuen Zufallswürfe beim erneuten Öffnen.
- Vollständig geerntete Bäume regenerieren nach 60 Minuten.
- 17 Materialtypen im Rucksack, zusätzlich 3 Tierbegegnungen im Entdeckungsbereich.
- Stein und Schrott behalten das bisherige Sammelverhalten.
- GPS, Demo, Karte, Reichweitenkreis, Zoom, Drehung, Export/Import und getrennte Speicherstände bleiben erhalten.

## Installation / Update

1. `index.html` aus dieser ZIP-Datei entnehmen.
2. Im bestehenden GitHub-Repository die bisherige `index.html` im Hauptverzeichnis ersetzen und committen.
3. Die GitHub-Pages-Website mit `?v=0220` am Ende neu laden.
4. Oben muss die Versionsnummer **V0.2.20** stehen.
5. Im Demo-Modus zu einem Baum laufen bzw. auf der Karte in seine Nähe tippen. Baum innerhalb 50 m öffnen.

## Hinweise

- Es handelt sich um einen mobilen Web-Prototyp; der Test mit echtem Android-GPS und Netzwerkdaten steht noch aus.
- Die Karte benötigt für reale Kartendaten Internet; sie kann bei Bedarf auf ihre Ersatzdarstellung zurückfallen.
- Vor dem Update lässt sich der bestehende Spielstand unter **Mehr → Export** sichern. Der bekannte lokale Speicher-Schlüssel wird beibehalten.
- Sammelpositionen sind nicht auf Erreichbarkeit überprüft. Keine Privatgrundstücke, Bahngleise oder gefährlichen Bereiche betreten.
