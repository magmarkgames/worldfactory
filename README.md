WELTWERK v0.2.3 Sky World

Alle eigenen Dateien liegen auf einer Ebene. index.html ins Hauptverzeichnis von GitHub Pages hochladen.

Neu: Himmel und perspektivisch auf dem Boden liegende Kartenfläche. Der 3D-Look ist CSS-2.5D, keine echten 3D-Gebäude. GPS, Demo, Inventar und Drops bleiben enthalten.

Hinweis: Kartenkacheln benötigen Internet und werden von OpenStreetMap geladen. GPS benötigt HTTPS und Standortfreigabe.
