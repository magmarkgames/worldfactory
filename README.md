# WELTWERK v0.2.8 – Stable World

Die bisherige riesige gekippte CSS-Kartenfläche wurde durch einen Canvas-Renderer ersetzt.
Dies beseitigt den Wechsel zwischen Himmel-only und Straße, indem nur noch eine gemeinsame
Kartenprojektion für Boden und Rohstoffpunkte verwendet wird. Ressourcen sind wieder anklickbar;
die Größe bleibt beim Drehen konstant.

## Installation

Die `index.html` direkt im Hauptverzeichnis des GitHub-Repositories ersetzen.
Für die neue Version `?v=028` an die URL hängen.

## Hinweise

Echte OSM-Kartendaten benötigen Internet. Bis zum Laden der Kacheln wird eine einfache
gezeichnete Straßenfläche gezeigt. Die Spielmechanik bleibt weiterhin ein Prototyp; Fundstellen
sind noch nicht auf sichere Zugänglichkeit überprüft.
